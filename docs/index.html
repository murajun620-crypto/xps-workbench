Help

  1. Open a CSV, TSV, TXT, XLSX, or VAMAS file. Use Spectrum to select a measurement for analysis and All spectra to overlay the measured curves at their applied energies.
  2. Enter an energy offset, or enter the measured and reference energies of a known peak. Shifted CSV exports the selected spectrum's full data. Shifted XLSX puts each spectrum's shifted energies and measured intensities on its own sheet.
  3. Choose a background method and an analysis range. Shirley and Linear use the intensities at the range endpoints.
  4. Add peaks and adjust them in the plot. Drag a circle to change position and height, or a half-height diamond to change FWHM. The residual updates as you adjust the model. Run fit uses the current values as its starting point.
  5. To fit a doublet, select Add doublet and click the primary line. The Si 2p defaults are 0.606 eV separation and a 2:1 primary-to-secondary area ratio. Edit these in Constraints. Both lines share FWHM and line shape.
  6. Save project stores the original measurements and analysis for every spectrum in one .xpsproject file. Use Open file to resume from that project.
  7. Export CSV to reopen the selected spectrum and its model, components, and residuals in Workbench. Plot Launcher and XPS Fit CSV also include the residuals.

Pseudo-Voigt combines Gaussian and Lorentzian profiles of equal FWHM. Areas integrate the full component profile. Residuals are measured intensity minus the total fit.
